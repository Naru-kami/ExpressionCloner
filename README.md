# Expression Cloner

Clone emojis and stickers to your servers, by doing `right-click` -> `clone emoji/sticker`.
This is a port of the [Vencord](https://github.com/Vendicated/Vencord/blob/main/src/plugins/expressionCloner/index.tsx) plugin.

## Installation
- Install [BetterDiscord](https://betterdiscord.app/)
- Download `ExpressionCloner.plugin.js`
- In Discord, go to the BetterDiscord settings and select `Plugins`.
- At the top, click `Open Plugins Folder`.
- Move the plugin file into the Plugins folder.
- Enable the plugin.
